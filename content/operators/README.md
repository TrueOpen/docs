# Network Operators

Operate Validator and Builder infrastructure on TrueOpen.

This section is for operators of chain and coordination infrastructure:

- [Validators](validators.md) run consensus and the TrueOpen application state machine.
- [Builders](builders.md) run Nexus to coordinate Task proposals, data delivery, and transaction relay.

These roles do not provide model inference merely by running their infrastructure. To supply AI compute, use the [compute provider guide](../providers/README.md).

Validator and Builder guides will cover requirements, installation, configuration, network enrollment, monitoring, upgrades, recovery, and security. Exact commands will be published with supported release artifacts and network parameters.

For the responsibility boundaries between Validators, Builders, and Cortex Nodes, see [Participants](../overview/participants.md) and [Architecture](../overview/architecture.md).

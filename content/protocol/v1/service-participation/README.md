# Service participation

Service participation connects long-lived provider identity with Task-specific responsibility.

- [Staking and penalties](staking-and-penalties.md) defines the ServiceBond, operator and service-key roles, Task liability, penalties, recovery, unbonding, and exit.
- [Models and profiles](../foundations/models-and-profiles.md) defines what a Cortex Node can declare support for.
- [Candidate selection](../tasks/candidate-selection.md) defines how eligible providers volunteer and receive Task duties.

Consensus stake and service responsibility are separate security domains. Providing inference or verification capacity does not make an operator a Validator, and ordinary service faults do not consume Validator consensus stake.

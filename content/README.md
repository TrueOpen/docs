# TrueOpen documentation

TrueOpen is a purpose-built network for AI inference tasks. It coordinates task execution and independent verification, provides a challenge process for disputed results, and settles accepted outcomes on-chain.

## Choose your path

### Understand TrueOpen

Start with the [Overview](overview/README.md), then explore the [system architecture](overview/architecture.md) and [participants](overview/participants.md).

### Provide compute

Use the [compute provider guide](providers/README.md) to decide whether to run a Cortex Node, prepare the host, join the network, perform duties, monitor operation, and exit safely.

Adapter developers can follow [Model integration](providers/model-integration/README.md) within the provider documentation.

### Develop an application

Use the [developer documentation](developers/README.md) to submit Tasks, track execution, retrieve results, and challenge an outcome.

### Operate network infrastructure

Use the [network operator guide](operators/README.md) for Validator and Builder responsibilities. Compute providers should use the separate provider guide.

### Study the protocol

The [Protocol](protocol/README.md) explains design principles, trust assumptions, algorithms, and versioned rules. Its [Task lifecycle](protocol/v1/tasks/README.md) follows execution from submission to finality.

### Look up a term

Use [Reference](reference/README.md) for terminology and supporting resources.
